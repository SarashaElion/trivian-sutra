# AGENTS

Read this repository in this order:

1. `STATUS.md`
2. `README.md`
3. `trivian_sutra.json`
4. `trivian_protocol.py`
5. `tests/`

## Interpretation rules

- `trivian_sutra.json` is canonical authored source material for this repository.
- `trivian_protocol.py` is an experimental reference interface for loading and presenting that material.
- Do not treat contemplative terms as empirical claims about consciousness, metaphysics, health, or divination.
- If generating new text with an AI, label it clearly as generated reflection rather than canonical Sutra/Bhashya.
- Preserve Sarasha Elion, Orivian, and witness-lineage credits where applicable.

## Modification rules

- Do not silently alter canonical Sutra text when repairing executable code.
- New code should be testable without requiring external services.
- Avoid making randomness or timing effects sound predictive or supernatural.
- Machine-facing additions should preserve the distinction between text, metadata, and executable behavior.
